# 学习行为与课程成绩：中期研究方案

本周建议把目标收敛为：检验学习日志能否为这 3 名同学的小测成绩预测增加信息。现有情景不足以支持“复杂模型优于简单回归”，也不足以支持“改变学习行为能提高成绩”。下周完成数据核对和公平的最小比较，即使新增行为变量没有改善预测，也能形成有效的中期成果。

## 已知材料与本轮实际完成

用户提供的事实只有：大学生高级项目小组；研究学习行为与课程成绩关系；3 名同学各有 100 天日志及每周小测成绩；下周中期汇报；设备为普通笔记本；原先想用复杂模型证明优于简单回归。

本轮实际完成的是研究规划。没有收到日志、成绩表、字段说明或运行结果，未执行数据处理、统计分析或模型训练，未检索文献。本文的划分、模型、工作安排和完成判据都是建议方案，不是已发生的结果或已获导师认可的要求。

## 收敛后的问题

建议问题：在同一门课程、成绩可以对照的前提下，使用小测开始前 7 天的一项学习行为，能否改善对这 3 名同学随后当次小测成绩的预测，相比只使用学生身份及最近已公布小测成绩的线性模型？

预测时点固定在当次小测开始前。因此，这是“掌握前 7 天日志后的预测”，不能表述成提前一周就能预知成绩。分析对象是学生—测验记录，参与者层面的独立来源只有 3 人；同一学生各周记录存在相关性。不能把约 300 个学生日当成 300 个独立受试者，也不能把同一次小测成绩复制到每天来扩充监督样本。实际可配对的测验条数须读到数据后统计。

如果 3 人没有可对照的共同课程或测验，先缩为可比的课程子集；没有可比子集时，分别做个人描述性案例，不硬合成一个模型排名。结论范围始终限于这 3 人及其观察期内的测验，暂不回答新学生、其他课程或期末总评的泛化问题。

## 先核实哪些前提

| 待确认项 | 为什么影响方案 | 查证来源与缺失时的处理 |
| --- | --- | --- |
| 日志有哪些实际字段、单位和记录时间；漏记是否可区分于零学习 | 决定能否构造有意义的行为变量 | 查日志表头和记录说明。优先使用实际记录的学习时长，汇总前 7 天总量；没有时长时，仅在日志明确记录了“是否学习”后改为学习天数。只有填写日志的时间不能自动视为学习行为；没有可解释字段则先做数据可用性报告 |
| 小测日期、开始时间、满分、对应课程及成绩公布时间 | 决定目标可比性与信息是否提前可用 | 查成绩表及课程记录。满分不同时按已知满分换成百分制，说明这没有消除试卷难度差异；最近成绩必须在预测时点已经公布。未知关键时间则不声称完成无泄漏验证 |
| 100 天内日志的完整性、重复和人与记录的对应关系 | 决定有效测验数与排除规则 | 建立匿名学生标识及测验配对表。漏记不填成零；主分析先使用前 7 天记录完整且有已公布历史成绩的测验，并报告每人排除数量和原因；若剩余太少就缩为描述分析 |

这些核对可以由小组在第一天完成，不需要先等待导师替小组选择模型。课程可比性、日志字段含义仍无法查明时，再带着上述具体问题讨论。

## 最小对照与评价

先只保留一项行为变量，不增加深度模型、自动特征筛选或大规模调参。最小比较如下，三者使用完全相同的可评价测验记录。

| 方法 | 输入与作用 |
| --- | --- |
| M0：沿用最近成绩 | 直接预测为该生预测时点前最近已公布的小测成绩，检验模型是否超过一个直接可用的参照 |
| M1：历史成绩线性回归 | 学生固定截距加最近已公布成绩，控制稳定的个人成绩水平和最近表现 |
| M2：加入行为的线性回归 | 在 M1 的完全相同设置中只增加前 7 天的一项行为汇总，回答行为是否增加预测信息 |

这里的主要比较是 M2 与 M1，改变的只有行为变量。M0 用于识别“两个回归都不如直接沿用历史成绩”的情况。它们不构成复杂模型优越性的验证；这是本次主动收敛的研究范围。

将可用测验时点排序，共 T 个时点，前 ceil(0.6T) 个作为初始训练段，其后逐次向前预测。相同测验时点的 3 人记录一起进入评价；对时点 t 的预测只使用严格早于 t 的已公布成绩和当时可用日志。较早评价时点的成绩公布后，可以用于后续时点训练，按此规则依次前推。不能随机打散学生—周记录，也不能把同一周其他同学的待预测成绩放入训练集。

在查看评价结果前锁定行为变量、缺失处理、划分和指标。若做缩放或其他拟合处理，只能在每轮训练数据上拟合。训练数据必须覆盖待预测学生，且足以使回归参数可识别；否则缩减为 M0 和描述分析，不用复杂模型填补数据不足。若实际只能评价一两个测验时点，误差仍可列出，但只说明流程试跑情况。

主要指标用 MAE，即“预测分数与实际分数之差的绝对值，再取平均”。先报告每位同学的 MAE 和评价测验数，再对 3 人的 MAE 等权平均，单位为原成绩分或统一后的百分制分。若某人没有可评价记录，应明示，不能声称已完成 3 人评估。保存每条预测，并列出各人的 MAE(M2) − MAE(M1)；负数才表示本次误差下降。

同时查看每个评价时点的误差及某一名同学的结果是否主导汇总，记录实际运行时间。可以报告观察到的差异，但不以这些重复测量计算面向学生总体的显著性或泛化区间；不同随机种子也不会增加参与者数量。行为系数只作条件关联的探索性描述，课程难度、复习内容、身体状态等替代解释尚未被排除。

## 下周可执行工作

下表是按距离汇报约一周制定的建议安排。数据由小组提供后执行；如无法按时取得数据，按后文“中期完成判据与可得结论”中的缩减产物汇报，不补写结果。

| 时间 | 输入与任务 | 产物及完成判据 |
| --- | --- | --- |
| 第 1 天 | 收集日志、成绩表和字段说明，核对上述前提 | 数据字典、匿名配对清单、每人有效测验数、缺失与排除表；每项关键未知有来源或明确缺口 |
| 第 2 天 | 按核对结果确定一个行为变量、预测时点与划分 | 一页锁定方案及学生—测验分析表；每行可追溯到原记录，行为窗口和历史成绩都在预测时点前可用 |
| 第 3 天 | 在最早的可评价时点小规模试跑 M0、M1、M2 | 逐条预测表及一次人工复核；确认样本对应、时间顺序、单位和训练处理正确，记录实际耗时；不可识别时执行缩减方案 |
| 第 4—5 天 | 不改方案，完成全部预定时点的前推评价 | 按人和按时点的误差表、三方法比较图、原始预测文件；汇总值能由逐条预测复算，失败或无法预测的记录有原因 |
| 第 6 天 | 核对结论与图表，整理中期材料 | 5 页左右：问题与边界、数据可用性、对照设计、实际结果、限制与下一步。每项结果可追溯到表格；没有结果的页明确写“计划/尚未执行” |
| 第 7 天 | 小组相互解释设计，预留修正时间 | 能说明为什么日记条数不是独立样本数、为什么不能随机划分、行为变量的增益如何判断；修正文字和图表，不为获得好结果更换模型 |

普通笔记本可优先承担少量线性回归和表格汇总，具体耗时以试跑记录为准。保持原始数据只读，派生表与结果放入独立实验目录；保存数据版本、有效设置、代码版本、运行方式和异常。本轮没有实际建立这些数据或实验文件。

## 中期完成判据与可得结论

有真实数据时，中期完成的标准是：核清数据可用性；锁定并落实时间划分；在共同记录上完成最小对照，或有依据地退回描述分析；交付可复算的结果及限制。改善幅度不设为验收门槛。若 M2 未改善，保留“本次评价未观察到新增行为变量的预测收益”；若有改善，只表述为“在这 3 人、这些前推时点和当前定义下，观察到预测误差下降”，同时报告实际数值及其分布。

只有当前情景材料时，能够得出的是研究范围与数据限制，不能得出行为和成绩已经相关、复杂模型更好、学习行为导致提分，或能推广至大学生总体。没有按时拿到数据时，合格的缩减中期产物是上述规划、字段需求和空表结构，并如实说明实证分析尚未开始。最有价值的后续补充是更多独立参与者和后续连续测验，而不是把已有日记拆成更多样本。
