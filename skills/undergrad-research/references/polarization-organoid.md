## 研究问题与事实边界

目标是用多参数偏振图像与超像素图比较无监督分区，描述区域组成及空间异质性。项目包含 7 个 ROI，采集记录含同一来源标识；独立患者、类器官和切片数量尚未确认。文件数和像素数不能当作独立生物样本数。

幻灯片提出“结构区域识别”和退偏、延迟等候选特征；实际代码与当前数据前提决定已经实现且可解释到哪一步。未有组织学参考或专家确认时，输出称为偏振特征类别，不能直接命名细胞核、纤维、坏死或报告诊断准确率。

## 公式与前提

采用一基行列下标、Stokes 顺序 I,Q,U,V，`S_out = M S_in`。当数据尚未归一化且 M11 可作有效分母时，`mij = Mij / M11`；若已归一化则不要重复除。项目中 `FinalM11` 接近 1 支持 `as_stored` 这个探索设置，但不单独证明仪器标定、阵元顺序和归一化已经确认。

| 参数 | 在归一化阵元上的公式 | 解释与代码对应 |
| --- | --- | --- |
| PL | `sqrt(m21^2 + m31^2)` | 线性起偏能力；`FinalM21, FinalM31`；体现非偏振入射产生线偏振分量的能力 |
| DL | `sqrt(m12^2 + m13^2)` | 线性二向色性；`FinalM12, FinalM13` |
| qL | `sqrt(m42^2 + m43^2)` | 线偏振到圆偏振的耦合幅度；`FinalM42, FinalM43` |
| rL | `sqrt(m24^2 + m34^2)` | 圆偏振到线偏振的耦合幅度；`FinalM24, FinalM34` |
| D | `sqrt(m12^2 + m13^2 + m14^2)` | 总二向色性；比 DL 多圆偏振相关项，用作单独特征消融 |

公式依据是本地肝纤维化研究补充材料的物理第 3 页 Table S1，并与 `analysis/polar_pipeline.py` 的 `parameters()` 核对。原文把 qL/rL 归入线偏振与圆偏振相互转换相关的量；它们是无量纲幅度，不能直接当作以 rad/degree 表示的相位延迟。

项目沿用“二向色性”称呼 DL/D；讲授术语时说明 diattenuation 是不同偏振态的衰减差异，不应把所有差异都解释为吸收导致的 dichroism。含义应随参数定义与测量条件核对。

讲解时可用 `m21=0.3, m31=0.4 → PL=0.5` 说明两分量合成；这是算术示例，不是本地数据或一份完整物理矩阵的验证。解释数组索引时明确 `M21` 对应一基第 2 行第 1 列，不能因为 Python 使用零基而错取阵元。

阵元来自测量，不是为得到某个参数值而自由挑选的输入。先在同一像素上计算参数图，再按区域统计；先平均有正负号的阵元再开方可能产生取向抵消，也不等于参数的区域均值。若研究这个差别，应作为不同统计定义报告。

## 学习时容易混淆的概念

| 概念 | 本项目需要保持的区别 |
| --- | --- |
| SLIC 超像素与综述中的偏振超像素 | 当前图节点是空间邻近的 SLIC 区域；综述中的偏振超像素按偏振特征相似性归组，不要求空间相邻。不能直接把后者当作可接触的组织小块构图。依据为本地综述第 7 至 9 页相关段落 |
| 超像素与最终类别 | 超像素数决定计算单元精细度，K 决定聚类组数；7 个 ROI 不是 K=7 的理由 |
| 二维切片与三维类器官 | 当前空间统计描述切片平面，不能直接声称已经量化三维内部结构 |
| 结构敏感性与空间分辨率 | 对亚细微结构变化的偏振敏感性不单独证明能直接分辨或重建相同尺度的结构；引用“超分辨”时追问实际测量与验证 |

概念学习可按“测量 → 数值参数 → 区域特征 → 图表示 → 分组 → 统计与参考解释”重建输入输出；不把降维、聚类和病理解释合并为一个算法结论。

退偏与相位延迟需要完整矩阵及约定明确的分解。案例的抽样诊断采用 I,Q,U,V 和相干矩阵半正定条件；在自动掩膜内每 16 个原尺寸像素抽样，24950 点中 393 点通过严格检查。这个比例只适用于给定采样、掩膜、约定和容差；不证明所有像素的通过率，也不能确定标定或噪声的具体责任。重构残差小仍可能存在物理性问题。检查依据见 [原始研究](https://academic.oup.com/bioinformatics/article/40/7/btae348/7687046)。

因此案例当前把未经物理性确认的退偏/延迟作为诊断值，不作为可靠特征并入主分析。局部平均后的通过率改变不能称为“完成校准”；任何物理约束修正都需保留原矩阵、报告改变量和边界混合影响。这里的诊断结果不能变成“所有新偏振数据都不可用”的规则。

## 已实现方法与受控比较

当前有效配置支持以下四种方法，VGAE 尚未实现；旧 v1 设计把 DGI 写作可选项的状态已被代码和运行记录更新。

| 方法 | 在案例中回答什么 | 与原始方法的关系 |
| --- | --- | --- |
| 区域偏振特征 + K-Means | 原始特征本身能分开什么 | 必要的简单基线 |
| SGC 式固定传播 + K-Means | 邻域传播如何影响分离与连续性 | 借用固定图传播；不是原论文的有监督分类实验，见 [SGC](https://proceedings.mlr.press/v97/wu19e.html) |
| GAE + K-Means | 学习连接重构表示的影响 | 本项目使用确定性 GAE，不把它称为 VGAE；方法来源见 [原文](https://arxiv.org/abs/1611.07308) |
| DGI + K-Means | 以扰动对比学习区域表示的影响 | 与 GAE 训练目标不同；见 [DGI](https://arxiv.org/abs/1809.10341) |

案例的不变量：

- SLIC 使用 PL、DL、qL、rL 四通道，`convert2lab=False`；显示/分割用分位缩放与特征统计分开。区域特征为未按显示范围裁剪的各通道均值、标准差。
- 空间边只连接同一 ROI 内接触的超像素，不跨背景或跨 ROI。相似度边给空间邻居赋权，不暗中改成任意全局 kNN 图。GAE 负采样和 DGI 扰动也限制在各 ROI 内。
- 当前探索使用共同特征处理、共享编码器和各方法在 7 个 ROI 上共同拟合的聚类中心；这不构成未见患者验证。
- 四参数等权、增加 D 等权、四参数相似度加权三组分别改变一个因素。增加 D 时保留四通道 SLIC 输入；逐 ROI 核对掩膜、超像素和基础参数图一致。
- 历史三组设置为约 500 个超像素、K=4、5 个种子、GAE/DGI 100 轮。它们不是最佳参数或通用门槛，调整时另建配置与运行目录。

## 如何解释这些结果

共同评价空间是四参数均值和标准差组成的 8 维空间；加入 D 的实验仍在这个空间比较。各方法自身嵌入的轮廓系数另列。不同种子 ARI 描述稳定性；连通域、异类邻接比例与边界描述空间分布；面积按掩膜内分析网格像素加权，Shannon 熵只描述组成多样性。

在已有三组汇总中，加权边改善了图方法相对等权边的共同空间轮廓系数，但该指标上基线仍更高。不能据此称图方法识别组织更准确，也不能仅凭更平滑的图称结构更合理。方法间类别号与颜色不自动对应。跨 ROI 的统计只作描述性汇总，不把未确认独立的 ROI 当作独立患者。

所有现有组织掩膜仍是自动草稿；ROI 6 低纹理孔洞是需复核的已知问题。新增人工掩膜应与原始阵元同尺寸、同坐标，按现有项目约定排除背景/腔隙，并说明谁以什么参考核对。几何合法与人工认可分别记录。
