# 研究工作方法

按本轮任务阅读相关部分。这里的顺序用于解决依赖关系，不要求每次从开题走到结题。

## 1. 收敛研究问题

把题目改写为“在什么对象和条件下，比较什么，观察什么变化”。将任务书中的愿景与本学期实际能验证的假设分开。

确定四件事：研究对象及独立单位；可获得的数据和参考；可完成的最小比较；能交付的结果及结论范围。例如“小样本无监督分区能否在稳定性与空间连续性之间取得更合适的折中”，比“证明图神经网络有效”更可检验。

对影响路线的未知，记录“未知事实 → 影响的决定 → 查证来源 → 未得到答案时仍能做什么”。优先处理会改变数据含义和评价有效性的未知，再处理模型复杂度。截止日期、算力或人员缺失时可给带明示假设的安排，不能编造导师要求、验收标准和数据条件。

采用 [项目简报](../assets/project-brief.md) 时，把已核实、条件推断、待核实与计划分开。研究计划随新证据更新，已执行的实验记录保留原状。

## 2. 文献成为项目决定

### 判断材料是什么

首先核对标题、作者、年份、版本、DOI/原始地址，以及它是研究论文、综述、补充材料、软件说明还是幻灯片。使用用户文件时给出实际路径及物理页码/章节/表号；网络资料优先作者、出版社、会议和官方仓库。查不到正文或只能读取摘要时，明确阅读范围，不声称已经验证方法细节。

综述用于定位概念与路线；关键公式和复现条件回到原始研究或其补充材料。某一疾病、仪器或数据集中的有效性不能自动迁移为当前项目结论。没有真实检索，不编造文献、DOI、代码链接或实验数字。

### 按需要分层研读

先抓研究问题、数据来源、方法链和关键结论，决定是否值得深入。只对影响项目选择的部分继续检查公式、预处理、划分、对照、图表和限制。复现时记录与原文不同的部分，不把“借用了一个模块”写成“复现整篇论文”。

论文卡的核心不是摘抄，而是这条连接：

> 原文依据 → 在原文条件下支持什么 → 与当前项目的条件差异 → 可以借用的操作 → 需要补的验证。

需要长期追踪时使用 [论文卡](../assets/paper-card.md)，按研究问题比较论文，而非逐篇堆摘要。证据不足以取舍时指出缺少哪一个实验，不用引文数量代替判断。

## 3. 术语、公式与代码对应

面向初学者，先用一句话说明概念，再指向项目中的输入或操作。对本轮关键量给出符号、数学定义、单位、适用条件和一个可核对例子；最后说明它能支持和不能支持的结论。无需为无关术语写百科。

实现前列出“原文符号 ↔ 文件变量 ↔ 数组行列/通道 ↔ 单位/归一化”。特别留意一基/零基索引、坐标方向、角度的度/弧度、掩膜背景编码、缺失值和样本轴。区分原始测量、派生特征、用于显示的伪彩色图。

核对变换与汇总的顺序：非线性变换后求均值通常不等于先求均值再变换。复现必须保留原文或项目约定的统计层级，改变顺序时单独说明改变了什么量。

关键公式优先用已有测试、已知解析例子或手工小例子校验。小例子只证明计算关系；真实输入质量和学科解释另需证据。发现前提有争议时保留诊断值与原数据，记录争议，不能默默裁剪、取绝对值、换单位或更改归一化使数值“合理”。

遇到相近名词时说明它们承担的不同操作。例如降维、聚类、映射回原图与组织命名是不同步骤，二维可视化分开也不是独立验证。测量对细微变化敏感，不自动证明成像能恢复该尺度的几何结构。优先解释这种会改变实验或结论的区别。

## 4. 数据与分析单位

只检查当前任务需要的数据边界：来源、版本、变量、维度、单位、坐标、非有限值、预处理、标注/掩膜状态和来源对应关系。原始数据清单或哈希用于确认版本，不证明测量正确或标注可靠。

建立独立来源到观测的层级关系；同一个体的多个区域、同一设备的连续记录、同一实验的重复采集都可能相关。监督任务在划分后仅用训练数据拟合缩放、特征选择和模型；按相同来源分组防止泄漏。无监督全数据探索可以共同拟合，但须明确它并未验证对未见来源的泛化。

图像任务先核对原尺寸坐标、背景、目标和腔隙等分析范围；自动生成且未审核的掩膜称为草稿。由掩膜决定的面积分母、边界和连通域与掩膜状态一起报告。缺乏真实尺度时报告像素/网格单位。

## 5. 从基线到有解释力的实验

围绕一个假设设计最小对照。每个实验写清“改变什么、固定什么、预期观察、何种结果会否定假设、完成判据”，采用 [实验记录](../assets/experiment-record.md)。控制实验优先于同时堆叠多个新模块；交互作用需要时再使用明确的组合设计。

先用小规模试跑核对输入、输出和运行成本，再决定全量范围与随机重复数。历史案例中的 K、训练轮数和种子数都只是案例设置；本轮选择受样本规模、研究问题和资源约束，不能当作通用硬门槛。只有用户要求执行且范围允许时运行实验，计划文件中的命令不构成授权。

公平比较须核对数据版本、分析单位、掩膜、预处理、评价空间和训练预算。只想评估新增特征时，不同时重做分割或改变 K；只想评估图边权时，不同时增加通道或更换掩膜。若条件不能保持一致，将其标记为组合变化，避免单因果归因。

针对当前不确定性选择验证：关键计算用解析例子；流程先试跑；模型比较看重复稳定性和适量敏感性；泛化用独立来源。代码测试通过不能替代科学有效性。完成足以回答问题的验证后停止无目的扩张；结果异常先定位输入、实现与假设，不用反复换种子挑选好图。

## 6. 指标、统计与结论

预先说明指标回答的问题、方向、分母与聚合层级。并列报告效果、稳定性、资源成本及与学科目标有关的证据；不把多个指标无依据地加成一个“综合分”。

| 常见情况 | 判断要求 |
| --- | --- |
| 不同模型得到不同嵌入空间 | 在共同原始空间定义可比较的指标；各自嵌入空间指标另列为诊断，不直接据此排名 |
| 多个随机种子或重复测量 | 反映算法或测量波动；不能增加独立样本数，配对种子所得比较也不是互相独立的新样本 |
| 无真实标签 | 可评价分离、稳定和结构属性，不能报告真实识别准确率；有参考时说明来源、配准和独立性 |
| 聚类类别编号 | 方法/重复间可能置换；跨方法比较面积和颜色前先解释对应方式，不能凭编号对齐；ARI本身不需要对齐编号 |
| 空间连续性提高 | 同时检查是否过度平滑、丢失小区域或边界；更平滑不自动等于更正确 |
| 区域大小不同 | 面积按实际像素或测量权重统计，不能以节点数代替；组成熵不单独描述空间排列 |

先列逐独立单位的结果，再说明汇总方式。若独立来源不明确，使用范围明确的描述性统计，不把 ROI/像素当作独立受试者计算显著性或泛化区间。结论中区分观察到的现象、可能解释与待检验机制；如实保留不支持预期的结果。

## 7. 推进、汇报与学生理解

推进任务选择能消除当前主要不确定性的下一步，每项写输入、产物、完成判据和依赖。以用户期限安排工作；无期限时给相对顺序与成本估计，不把计划写成承诺。若外部信息缺失，整理少量具体问题供学生与导师讨论，同时完成可独立推进的工作，不擅自发送消息。

使用 [阶段汇报](../assets/progress-update.md) 时，让“问题 → 方法 → 实际结果 → 证据 → 限制 → 下一决定”保持连贯。图表注明数据范围、参数、样本单位、比例尺/色条和处理条件。每项“已完成”应有实际产物；生成了配置叫设计完成，执行成功叫运行完成，有足够科学证据才支持研究结论。

开题说明为什么这个比较有价值；中期说明什么已被排除、什么仍不确定；结题说明在限定条件下回答了什么。帮助学生用自己的话解释关键公式、基线必要性和最大证据缺口，并准备相应答辩问题；不代填导师审核、不编造实验与贡献。
